## Today's Game: Neon Cosmic Catcher 🚀

A simple but addictive HTML5 Canvas game. Control a neon paddle to catch falling yellow stars for points while avoiding red asteroids that cost you lives.

### How to Play
- Use **mouse** to move the paddle, or **Arrow keys / A D**
- Catch yellow stars (+10 points)
- Avoid red asteroids (lose a life)
- Game speeds up as your score increases
- High score saved in your browser

### Play it
Open `index.html` in any modern browser, or enable GitHub Pages on this repo for online play!
